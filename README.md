# 小学口算天天练协议页

本目录用于部署《隐私政策》和《用户协议》静态页面，面向应用市场审核和用户公开访问。

## 页面

| 文件 | 用途 |
| --- | --- |
| `index.html` | 协议入口页 |
| `privacy-policy.html` | 隐私政策，中英文切换 |
| `user-agreement.html` | 用户协议，中英文切换 |
| `assets/legal.css` | 页面样式 |
| `assets/legal.js` | 语言切换逻辑 |
| `.nojekyll` | 避免 GitHub Pages 走 Jekyll 处理 |

## 发布链接

部署到 GitHub Pages 后，常用链接为：

- `https://tomkuku588-bot.github.io/StudentArithmetic/`
- `https://tomkuku588-bot.github.io/StudentArithmetic/privacy-policy.html`
- `https://tomkuku588-bot.github.io/StudentArithmetic/user-agreement.html`

英文页面可使用页面右上角切换，也可在链接后添加 `?lang=en`。
